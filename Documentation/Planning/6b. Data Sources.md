# Potential Data Sources

This document covers some potential sources for the data that would be needed for my site, and what areas they apply to.

### ONS Data
Here is the API for the ONS - https://api.beta.ons.gov.uk/v1. This needs to be explored to see what is available.

### Land Registry
House pricing data - https://landregistry.data.gov.uk/ looks like it has paid, transaction and HPI data

Price paid - https://www.gov.uk/government/collections/price-paid-data Actual download page https://www.gov.uk/government/statistical-data-sets/price-paid-data-downloads 

Transaction - https://use-land-property-data.service.gov.uk/datasets/td Actual download page https://use-land-property-data.service.gov.uk/datasets/td/download 

### EPC

https://get-energy-performance-data.communities.gov.uk/

base req URL https://api.get-energy-performance-data.communities.gov.uk
