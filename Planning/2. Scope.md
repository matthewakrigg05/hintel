# Scope

## Purpose

This document defines the scope of the Housing Intelligence Platform. It outlines the features planned for each release and helps ensure development remains focused on delivering value incrementally.

The scope is expected to evolve throughout the project as new ideas emerge, user feedback is gathered and technical understanding improves.

---

# Version 1 – Minimum Viable Product

## Objective

Provide users with a central location to explore housing market data for a given area using publicly available datasets.

### Features

* Search for a postcode, town or local authority.
* Display historical house price data.
* Show average property prices by property type.
* Display property transaction history where available.
* Show EPC statistics for an area.
* Display transport information.
* Display demographic and census information where available.
* Interactive charts showing historical trends.
* Interactive map visualisations.
* REST API for retrieving housing information.
* Automated data ingestion pipeline.
* Automated database updates.
* Responsive web interface.

### Non-Goals

Version 1 will **not** include:

* User accounts.
* Saved searches.
* Property price predictions.
* AI functionality.
* Payment processing.
* Mobile application.

---

# Version 2 – Intelligent Insights

## Objective

Move beyond displaying data by generating meaningful insights.

### Features

* Property price prediction model.
* Area growth prediction.
* Similar property comparison.
* Area comparison tools.
* Affordability calculations.
* Mortgage cost estimations.
* Interactive recommendation engine.
* AI-generated summaries for areas and properties.
* Explainable model outputs.
* Downloadable reports.

---

# Version 3 – Personalised Experience

## Objective

Deliver personalised recommendations and user-specific functionality.

### Features

* User accounts.
* Favourite areas.
* Saved properties.
* Email alerts.
* Personal affordability profile.
* Personalised AI recommendations.
* Watchlists.
* Property comparison dashboard.

---

# Version 4 – Commercial Platform

## Objective

Introduce commercial features while maintaining a high-quality free experience.

### Potential Features

* Premium property reports.
* Premium area reports.
* API access.
* Estate agent tools.
* Investor dashboards.
* Mortgage broker integrations.
* Affiliate partnerships.
* Payment processing.

---

# Technical Scope

The platform should demonstrate modern data engineering and AI product engineering practices, including:

* Automated data ingestion.
* Data validation.
* Data transformation pipelines.
* Relational database design.
* Analytics-ready data models.
* REST API development.
* Machine learning integration.
* Cloud deployment.
* Monitoring and logging.
* CI/CD pipeline.
* Documentation.

---

# Out of Scope

The platform will not attempt to:

* Compete directly with property listing websites.
* Host or advertise property listings.
* Replace estate agents.
* Provide legal or financial advice.
* Guarantee property valuations or investment performance.

---

# Success Criteria

The project will be considered successful if it:

* Demonstrates end-to-end data engineering capability.
* Demonstrates production-quality software engineering.
* Demonstrates practical machine learning integration.
* Demonstrates AI product engineering principles.
* Provides genuine value to prospective home buyers.
* Serves as a long-term portfolio project that can continue to evolve over time.

---

# Guiding Principles

Development decisions should prioritise:

1. Solving real user problems.
2. High-quality, trustworthy data.
3. Explainable insights over black-box predictions.
4. Incremental delivery.
5. Maintainable architecture.
6. Scalability for future growth.
7. Continuous learning through the development of modern data and AI engineering skills.
